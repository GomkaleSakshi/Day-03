# Employee Data Cleaning and Analysis

## Objective

This project demonstrates a beginner-friendly workflow for cleaning, analyzing, and visualizing a sample company employee dataset using Python.

## Dataset Description

`dataset/employee_data.csv` contains 34 rows: 32 employee records plus two deliberate duplicate rows. Its columns describe employee ID, name, age, department, gender, salary, experience, joining year, and performance score. The sample includes missing values and intentionally invalid numeric values so the cleaning process can be demonstrated. The generated cleaned file contains one row per employee.

## Technologies Used

- Python 3
- pandas for loading, cleaning, and analyzing tabular data
- matplotlib for charts

## Data Cleaning Steps

The cleaning script loads and describes the raw CSV, reports missing values, converts numeric columns to numeric types, and removes invalid values such as ages outside 18-70, non-positive salaries, negative or implausible experience, joining years outside 1980-2026, and performance scores outside 1-5. It removes duplicate rows, fills numeric gaps with the column median, fills missing names with `Unknown`, fills missing department and gender values with their most common values, and saves the result to `dataset/cleaned_employee_data.csv`.

## Analysis Performed

The analysis script reports total employees, average, highest, and lowest salary, average age and experience, department employee counts and average salaries, gender counts, performance-score counts and average, and the correlation between experience and salary. It also identifies the largest department and the department with the highest average salary. Results are printed and saved to `analysis/analysis_results.txt`. The correlation is descriptive and does not show that experience causes salary changes.

## Key Findings

For the included cleaned sample of 32 employees, the average salary is $76,187.50, average age is 34.1 years, and average experience is 9.0 years. Engineering is the largest department with 9 employees; Finance has the highest average department salary at $86,333.33. The experience-salary correlation is approximately 0.84, a strong positive association in this sample that does not establish cause and effect. Exact results are recalculated by the analysis script and written to `analysis/analysis_results.txt`.

## Run Locally

Open a terminal in the `Day-03` root folder. Install the required libraries:

```bash
pip install pandas matplotlib
```

Run the scripts in order so the cleaned dataset exists before analysis and visualization:

```bash
python data-cleaning/data_cleaning.py
python analysis/analysis.py
python visualizations/visualizations.py
```

Each script builds its file paths from its own location, so these commands work when run from the project root.

Running the scripts creates `dataset/cleaned_employee_data.csv`, `analysis/analysis_results.txt`, and the six PNG charts listed above. The cleaning and analysis scripts also print a concise summary in the terminal.
